# 0004 — Görsel Seviye 2, adım 1: KTX2 doku sıkıştırma

Durum: Kabul — 2026-09-22.

## Karar
Bütün raster dokular KTX2 (Basis Universal). GPU'da sıkıştırılmış kalıyor; Quest'te tarayıcı ASTC/ETC2'ye çeviriyor.

| Doku | Kip | Neden |
|---|---|---|
| Tablolar (9) | UASTC + RDO + zstd, sRGB | Yakından bakılıyor; fırça izi korunmalı |
| Parke | ETC1S | Masaüstünde UASTC ile yan yana farksız; dosya 4,9 → 0,8 MB |
| Panorama 4K | ETC1S | Yalnız pencereden, metrelerce uzaktan görünüyor |
| Model dokuları (9 × 1k) | UASTC; renk sRGB, ARM/normal lineer | Normal haritada RDO kapalı (yüzeyde kırıklık yapar) |

- Üretim: `scripts/lib/ktx2.ts` (ffmpeg çözer, `ktx2-encoder` WASM kodlar; global araç yok).
  `media:artworks` ham JPG'yi `content/media/raw/artworks`'te tutar, KTX2'yi `dist`'e yazar.
  `media:polyhaven` glTF'leri `KHR_texture_basisu` (zorunlu, JPEG yedeği yok) ile yeniden yazar.
- Sıkıştırılmış dokular yüklemede çevrilemez; düz dokular kodlamada Y'de çevrilir, glTF dokuları çevrilmez.
- Çalışma anı: tek `KTX2Loader` (`src/media/useKTX2.ts`); transcoder'ı three kendisi paketliyor (CDN yok, çevrimdışı çalışır).
  Modeller three'nin `GLTFLoader`'ı ile yükleniyor (drei/three-stdlib yükleyicisi three'nin KTX2Loader'ıyla uyumsuz).

## Etki (hesap, mip dahil)
GPU bellek ≈ 187 MB → ≈ 39 MB (tablolar 70 → 18, modeller 50 → 13, panorama 45 → 6, parke 22 → 3).
İndirme: `public/` 7,6 → 9,9 MB (UASTC model dokuları JPEG'den büyük); tablolar 4,2 → 17 MB (repo dışı medya).
Tablolar 1280 px uzun kenarda kaldı: Quest 3'te ~25 piksel/derece ile 2 m'den 1 m'lik tablo ~700 px; 2K kazanç getirmez.
